## Hi, I'm Mansoor Ahmed

Electrical engineering student building hands-on projects across embedded hardware, RF systems, and drone software. My work spans low-level microcontroller programming with Arduino and Python-based control scripts for DJI Tello drones, with a growing interest in machine learning and EV research.

### Featured projects

- **Car-Key-FOB-Hacking-Device-Using-Arduino-UNO-and-RF-Module** — Arduino UNO + RF module project exploring key fob signal capture and replay for security research.
- **4-DOF-Wifi-Web-Control-Motion-Repeater-Robotic-ARM** — A 4 degrees-of-freedom robotic arm controlled over WiFi through a web interface, built in C++.
- **DJITello-Facetracking-Script** — Python script that turns a DJI Tello into a face-tracking drone, holding a fixed safe distance from the subject.
- **Tello-Mnitoring-system** — Python-based image capture and monitoring system built for the DJI Tello platform.
